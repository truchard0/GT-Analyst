# LIVING MODEL - history is made, not foretold
Added 25 Nov 2026 (user: "make sure the gt bot is doing this", sharing a discussion of the approach). formal-game-theory
wins on validity; the outside-view rule (schema R25 / R26) stays in force: this skill supplies the reason for a
divergence, it does not remove the base rate. Doctrine §14 binds. The war-price ban is absolute.

## 1. THE STANCE
- **Actions make history.** The record says how often something happened, not what can happen. An actor's move can
  open a situation with no precedent (the 2024 election path is the house example: the prior actions built a juncture
  that the base rate could not see). Treat a base rate as an anchor to depart from with reasons, never as a ceiling.
- **Mechanism before frequency.** A forecast names the chain: who acts, why, with what, against whom, and what each
  step needs. A number without a chain is not a forecast.
- **The model is alive.** It is rebuilt by events as they happen, not fitted once to the past and then read.
- **Same mechanism at every scale.** People, firms, agencies, parties and states are all actors with interests,
  levers and constraints. Read a state the way you would read a person in the same position.

## 2. ON EVERY ANALYZABLE EVENT (write these four lines in the analysis)
1. **Actors at the levers.** Who decides, what they want (stated and revealed), what they hold, what stops them.
   Use the leverage map (`leverage-campaigns` §2) when a stronger actor is pressing a decision. A state is one actor
   only when its decision-makers agree; otherwise split it (doctrine §4).
2. **Structure change.** Does this event change the model's shape: a new actor, a new lever, a removed constraint, a
   new path, a dead path, a new edge between two lanes of the timeline? Write the change, then make it on the timeline
   web the same cycle (new node, pruned node, new shift edge). Changing only a probability is the weak case; say so
   when that is all it is.
3. **Juncture check (section 3).** Are we at a critical juncture? If yes, widen the spread and open the branches in
   section 4.
4. **Scale check (section 5).** Does the same mechanism run one scale up or one scale down? If it does, say where;
   independent scales count as separate lenses for conviction.

## 3. CRITICAL JUNCTURES (when the future is unusually open)
A juncture is a short window when the usual constraints are loose and one actor's choice can set a path for years.
Flag one when at least two of these hold, each with a dated item:
- **A constraint has just broken:** a rule, a norm, an alliance, a coalition, a market's assumption (for example a
  leader overturning a board, a court decision, an election that changes who controls a lever).
- **Actors are re-sorting:** sides changing, new coalitions forming, an incumbent's backers defecting.
- **A shock has made the status quo costly** for an actor who can move (loss domain, formal §7).
- **Information is suddenly public** that everyone knows everyone knows (formal §12.2, §12.8).
- **A deadline or a vote forces a choice** inside the window.
When a juncture is flagged: (a) no branch under that node may sit at 0 unless something makes it impossible; (b) the
spread of outcomes is wider than the base rate implies, so extreme branches get a floor (section 4); (c) the next
three dated items that would close the window are listed as checkpoints with shift edges.

## 4. PATHS WITH NO PRECEDENT
A branch with no historical case is opened, not dismissed, when its preconditions are ripe (doctrine §12.3):
- List the necessary preconditions for the path. Mark each materializing, mixed or absent, with a dated item.
- **All necessary preconditions materializing:** open the branch at 0.10 or more, even with no base rate. Say "no
  precedent; preconditions ripe" in the rationale.
- **Most materializing:** open at 0.05 to 0.10.
- **Few or none:** no branch; note it once in the analysis as a watched path.
- Ledger rows from a no-precedent branch keep the R26 divergence note (the preconditions are the divergence reason),
  stay inside 0.35-0.65 for decisions without an execution signal, and are tagged cluster `no-precedent` so their
  record can be read on its own.
- Track the preconditions every cycle. A precondition that reverses closes or shrinks the branch the same cycle.

## 5. THE SAME MECHANISM AT EVERY SCALE
Before ledgering, test the mechanism one scale up and one down:
- **Person -> institution -> state -> bloc.** Example: "an actor under pressure trades a concession for cover" can be
  a CEO and a board, a board and a regulator, a government and an ally, a bloc and a rival bloc.
- If the mechanism is visible at another scale in the current news, cite it: independent scales add a lens
  (conviction "multi-lens convergence" component). Correlated sources at the same scale do not.
- If the mechanism only works at one scale, say why (a constraint that exists there and not elsewhere). That is often
  where the forecast is weakest.

## 6. HOW THE MODEL CHANGES ITSELF
- Keep a dated **model log** in the analysis: structure changes (section 2.2) with the item that caused each.
- A structure change outranks a probability change. When news only moves odds inside the existing tree, ask once
  whether the tree itself is wrong before nudging numbers.
- Misses are scored by type: **wrong numbers** (the tree was right, the odds were off) versus **wrong tree** (the
  outcome had no branch, or was zeroed). A wrong-tree miss always requires a patch to this skill or the doctrine; it is
  never "variance". The Nvidia reinstatement of 23 Nov 2026 is the first recorded wrong-tree miss.

## 7. GUARDS
- **Not a license for drama.** Every no-precedent branch needs named, dated preconditions. "Anything could happen"
  is not a precondition.
- **Not a plot model.** Converging interests are not coordination (mechanism library MX-G2); Tier C hygiene applies.
- **Calibration still rules.** Base rates are kept and shown; departures are written as reasons and scored. If the
  `no-precedent` cluster scores worse than its stated odds over 10 resolved rows, the floors in section 4 are cut.
- **Facts and motives.** Documented actions with source and time; intentions written as inference.

46. **Structure line:** the change to the model's shape written and made on the timeline web, or "probability only".

48. **No-precedent paths:** any path whose preconditions are ripe has a branch at the section 4 floor, tagged.
